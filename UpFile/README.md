# UpFile - Tính năng Tải lên Tệp (Upload File)

Thư mục phát triển các tính năng và module liên quan đến việc tải lên tệp (upload file) cho hệ thống LDMega.

## Mục tiêu tính năng
- Hỗ trợ tải lên các định dạng tệp thông dụng.
- Tích hợp lưu trữ (Google Drive, Cloudflare R2, hoặc local storage).
- Quản lý trạng thái và tiến trình tải lên.

## Trạng thái
- **Trạng thái**: Đang khởi tạo và chuẩn bị phát triển.
