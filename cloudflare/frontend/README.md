# Cloudflare Pages Frontend (cloudflare/frontend)

Thư mục giao diện Web Dashboard tĩnh được thiết kế để triển khai trực tiếp lên **Cloudflare Pages**.

---

## 🚀 Cách Deploy lên Cloudflare Pages

### Cách 1: Sử dụng deploy.sh
```bash
./deploy.sh cf-fe
```

### Cách 2: Sử dụng lệnh trực tiếp
```bash
npx wrangler pages deploy public --project-name ldmega-frontend
```

Giao diện sẽ lập tức có liên kết dạng `https://ldmega-frontend.pages.dev` hoàn toàn miễn phí kèm chứng chỉ SSL!
